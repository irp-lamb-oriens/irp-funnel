🔬 HeroForm — Scroll Race Condition Test

BUGGY scroll: 0 px

🐛 Before patch

function formNext() {
  if (validateFormStep(step)) {
    formStep++;
    focusFormInput(step);
    // ↑ fire-and-forget — NOT awaited
  }
}

async function focusFormInput(step) {
  await tick();        // one rAF flush
  map[step].focus();
  // ↑ browser calls scrollIntoView()
  //   while translateY: 16px → 0 is
  //   still mid-animation → snap/jump
}

focus() fires while the element still sits at translateY(16px). The browser scrolls to a position that immediately shifts as the 500ms animation completes — producing the snap glitch.

✅ After patch

async function formNext() {
  if (validateFormStep(step)) {
    formStep++;
    await focusFormInput(step);
    // ↑ properly awaited
  }
}

async function focusFormInput(step) {
  await tick();
  map[step].focus({ preventScroll: true });
  // ↑ keyboard focus established
  //   without triggering auto-scroll
  //   mid-animation → no snap/jump
}

preventScroll: true decouples keyboard focus from scrollIntoView(). The 500ms CSS transition runs uninterrupted. Supported Chrome 64+, Firefox 68+, Safari 12.1+.
